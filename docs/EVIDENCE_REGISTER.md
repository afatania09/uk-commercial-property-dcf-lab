# Evidence & assumption register

A DCF is only as credible as its inputs. This register forces each important input to be classified rather than silently embedded in a spreadsheet.

## Evidence hierarchy used in this project

| Grade | Evidence type | Typical treatment |
|---|---|---|
| A | Verified completed transaction / executed lease evidence | Primary market evidence, subject to comparability |
| B | Reliable published transaction or letting evidence | Strong supporting evidence; verify where possible |
| C | Current marketing / asking evidence | Contextual evidence; not equivalent to an achieved transaction |
| D | Model assumption / scenario | Requires rationale, sensitivity testing and ideally market corroboration |

The grade is **not** an automatic weighting formula. Relevance, comparability, date, location, specification, lease terms and transaction circumstances still require professional judgement.

## Governance questions

Before accepting an output, ask:

- Is the valuation basis clearly identified?
- Are market-derived and investor-specific assumptions separated?
- Is the valuation date explicit?
- Could a third party trace each material input to its source?
- Have asking prices been distinguished from completed transactions?
- Have lease events been modelled rather than ignored?
- Are nominal/real assumptions internally consistent?
- Is growth double-counted in both cash flow and yield/discount assumptions?
- Is terminal value disproportionately large relative to total value?
- Have the most judgement-sensitive inputs been stress-tested?
- Has the result been reconciled against market evidence and another method/model where appropriate?

## Principle

> **Trace the evidence → state the assumption → model the cash flow → test the sensitivity → reconcile the conclusion.**
